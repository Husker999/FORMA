# FORME — сайт студии детейлинга

Демонстрационный проект для портфолио. FORME — вымышленная студия детейлинга и защиты кузова. Цены, контакты и «работы» на сайте условные и подписаны как демонстрационные.

Сайт написан на чистых HTML, CSS и JavaScript, без сборщика и без `npm install`. Единственная библиотека — three.js для 3D-сцены, она лежит в папке `vendor/`, поэтому интернет для работы сайта не нужен.

> Папка называется `forma`, а бренд на сайте — FORME: название студии в макете не менялось. Исходная папка проекта — `Desktop\910\forme`.

## Что работает, а что демонстрационное

| Функция | Как устроено |
|---|---|
| 3D-сцена первого экрана, «лампа осмотра», услуги, до/после, подбор услуги, FAQ, меню | Работают полностью в браузере |
| Заявка | Проверяет поля и собирает готовый текст: его можно скопировать или открыть в почтовой программе. Никуда не отправляется и не делает вид, что отправилась — об этом написано рядом с кнопкой |
| Цены «от», контакты, адрес | Условные, подписаны как демонстрационные |
| «Работы» и изображения услуг | 3D-визуализации одной модели, подписаны как визуализации; реальных автомобилей и клиентов нет |

## Ограничения

- Открытая двойным кликом страница (`file://`) показывает вместо живой 3D-сцены статичную картинку того же кадра: браузеры не загружают модули и модель с диска. Через любой сервер или хостинг всё работает.
- 3D-сцене нужен WebGL. Где его нет или включена экономия трафика, остаётся картинка.
- Модель автомобиля весит 2,3 МБ и загружается после первого экрана.
- `og:image` указан относительным путём — после публикации замените на полный адрес (см. ниже).

## Как открыть сайт на компьютере

Двойной клик по `index.html` откроет страницу, но 3D-сцена в первом экране не запустится: браузеры не загружают модули и 3D-модель с адресов `file://`. Вместо 3D будет показана статичная картинка того же кадра, остальное работает.

Чтобы увидеть всё, запустите локальный сервер. Два простых способа:

**Visual Studio Code.** Установите расширение **Live Server**, откройте папку проекта, нажмите правой кнопкой на `index.html` → **Open with Live Server**.

**Python** (обычно уже установлен на macOS и Linux). Откройте терминал в папке проекта и выполните:

```
python3 -m http.server 8000
```

Затем откройте в браузере `http://localhost:8000`.

## Как выложить в интернет

Подойдёт любой хостинг статических сайтов: GitHub Pages, Netlify, Vercel, Cloudflare Pages. Например, GitHub Pages: создайте репозиторий, загрузите в него содержимое этой папки, затем в настройках репозитория откройте **Settings → Pages** и выберите ветку `main` и папку `/ (root)`.

После публикации замените в `index.html` относительный адрес `og:image` на полный (`https://ваш-адрес/assets/img/og-cover.jpg`): мессенджеры и соцсети показывают картинку превью только по полному адресу. Картинку можно пересобрать скриптом `tools/build_og.py`.

## Структура

```
index.html              страница: все тексты и разметка
css/styles.css          оформление: цвета, шрифты, сетка, анимации
js/main.js              интерактив: меню, услуги, до/после, подбор, FAQ, форма
js/hero.js              живая 3D-сцена первого экрана и «лампа осмотра»
js/studio.js            3D-студия: свет, материалы, камера (общая для сайта и рендера)
vendor/three/           библиотека three.js r169 (MIT)
assets/img/             изображения сайта (WebP, по два размера каждое)
assets/models/          3D-модель автомобиля (.glb)
assets/fonts/           шрифты Roboto Flex и Golos Text (OFL)
tools/                  скрипты, которыми сделаны изображения и проверки (не нужны для работы сайта)
```

## Что где менять

| Что | Где |
|---|---|
| Тексты разделов | `index.html`, каждый раздел подписан комментарием `<!-- 1. HERO -->`, `<!-- 2. SERVICES -->` и т. д. |
| Цены услуг | `index.html`, раздел `SERVICES`: элементы `service__price`. Сноска о демо-ценах — под списком |
| Контакты | `index.html`, раздел `CONTACT`, блок `contact__details`. Адрес почты в `data-studio-email` используется и для кнопки «Открыть в почте» |
| Логика подбора услуги | `js/main.js`, объект `R` в разделе «6. Finder»: заголовок, текст и список вопросов для каждой пары ответов |
| Цвета | `css/styles.css`, блок `:root` в начале файла |
| Фотографии | `assets/img/`. Замените файл на свой с тем же именем и пропорциями, либо поменяйте путь в `index.html` |

## Как устроены главные функции

**Первый экран.** Сначала показывается картинка `hero-wide.webp` (или `hero-narrow.webp` на телефоне). Когда загрузится 3D-модель, на её место плавно встаёт живая сцена с тем же кадром. Курсор управляет «лампой осмотра»: полоса света проходит по кузову, а остальная студия чуть приглушается. На телефоне свет движется при прокрутке. Если WebGL недоступен или включён режим экономии трафика, остаётся картинка.

**До и после.** Два изображения одной и той же 3D-сцены: «после» — чистый лак, «до» — тот же рендер с помутнённым лаком, к которому программно добавлены круговые царапины, водные пятна и пыль (`tools/build_images.py`). Царапины нарисованы там, где они реально видны: вокруг отражений света. Разделитель двигается мышью, касанием и с клавиатуры (стрелки, Shift + стрелки, Home, End).

**Подбор услуги.** Два вопроса, результат обновляется сразу. Кнопка «Оставить заявку с этим выбором» переносит рекомендацию в форму: выбирает услугу и заполняет комментарий.

**Заявка.** Сервера нет, поэтому форма ничего не отправляет и не делает вид, что отправила. После проверки полей она собирает готовый текст сообщения, который можно скопировать или открыть в почтовой программе. Чтобы заявки приходили по-настоящему, нужен приём данных: например, сервис форм (Formspree, Getform), бот Telegram или свой сервер. Подключение делается в `js/main.js`, в обработчике `submit` формы.

## Откуда изображения

Все изображения на сайте — рендеры одной 3D-модели в одной виртуальной студии, поэтому они выглядят как единая серия. Фотографий реальных автомобилей и работ нет.

Модель: **«Car Concept»**, автор Eric Chadwick, Darmstadt Graphics Group, лицензия [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/), из [KhronosGroup/glTF-Sample-Assets](https://github.com/KhronosGroup/glTF-Sample-Assets/tree/main/Models/CarConcept). В основе — модель Unity Fan (CC0). Для проекта изменены материалы, свет и текстуры шин, удалены логотипы Khronos и 3D Commerce (лицензия на них не распространяется), модель сжата gltfpack. Указание авторства есть в подвале сайта — при любом использовании его нужно сохранить.

Перерисовать изображения (для продвинутых, нужен Python с пакетом `playwright`):

```
python3 -m http.server 8765 &
python3 tools/render_images.py tools/shots.json tools/out
python3 tools/build_images.py
```

Ракурсы, цвета и свет каждого кадра задаются в `tools/shots.json`.

## Проверка

`tools/check_page.py` открывает сайт в Chromium на пяти размерах экрана, ищет ошибки, битые ссылки и горизонтальную прокрутку. `tools/test_interactions.py` прокликивает все функции и проверяет результат.

## Перед использованием реальным бизнесом

- Заменить название, тексты и описание студии на реальные.
- Указать настоящие цены или убрать их, оставив «расчёт после осмотра».
- Указать реальные контакты, адрес и часы работы.
- Заменить визуализации в разделе «Работы» и в услугах на фотографии реальных автомобилей. Подписи «3D-визуализация» тогда нужно убрать.
- Подключить приём заявок (см. выше) и добавить согласие на обработку персональных данных и политику конфиденциальности.
- Проверить тексты о процедурах и сроках вместе со специалистами студии.
